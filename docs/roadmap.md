# Roadmap

1. Identity, workspaces, PostgreSQL foundation, and observable lifecycle
2. Safe, bounded evidence ingestion
3. Deterministic reviews, human decisions, and report exports
4. Acme FieldOps benchmark integration
5. Model-assisted findings and release evals
6. Signed self-hosted prerelease and recovery exercises
7. Bounded public-repository-only Railway beta
8. Temporary AWS and Azure reference proof
9. Evidence-backed public case study and stable-release criteria

Dates are not release promises. Every capability remains pending until its tests and operating evidence pass.
