# Governance

Jason Cochran is the initial maintainer and release manager. Decisions favor user safety, evidence, maintainability, and the same Apache-2.0 source for Community and hosted deployments.

Maintainers review issues and pull requests, record material decisions as ADRs, publish release notes, and disclose conflicts. New maintainers are added after sustained, constructive contribution and documented agreement from existing maintainers. Security reports follow `SECURITY.md`.
