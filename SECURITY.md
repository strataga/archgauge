# Security Policy

ReadyRay has no supported release yet. Do not expose it to untrusted evidence or production traffic.

Report suspected vulnerabilities privately through GitHub Security Advisories after publication, or through the security contact listed on jasoncochran.io. Do not include secrets or private repository content in email or public issues.

The project will publish supported versions, response expectations, remediation, disclosure, and credit with its first prerelease. See `docs/security/threat-model.md`.
